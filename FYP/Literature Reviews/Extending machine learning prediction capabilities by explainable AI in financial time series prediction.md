Applied Soft Computing 132 (2023) 109876, Çelik, İcan and Bulut out of the Faculty of Economics and Administrative Sciences at Ondokuz Mayıs University. Daily direction prediction on six index closes, SP500, NI225, XU100, KOSPI, DAX and FTSE100 over 2012 to 2021, using a two-stage stacking ensemble the authors call EMD-ANNRC-RF: empirical mode decomposition splits the price series into intrinsic mode functions, one ANN regressor per IMF plus one ANN classifier on the hardest IMF feed a random forest, and the forest predicts tomorrow's direction. The contribution the paper actually cares about sits on top of that. <font color="#ffc000">LIME is run over the random forest to obtain a class probability for every individual prediction, that probability is read as a reliability score, and predictions whose score falls below a chosen threshold are simply not made.</font> Reported headline is 0.9913 accuracy on KOSPI, which is true and also only holds for 115 of 612 test days. Code is on Code Ocean as a reproducible capsule, which is more than almost anything else in my set offers.

This one is not a competitor architecture and I am not reading it as one. The ensemble is a fairly ordinary EMD-plus-ANN stack and the index-level target is not the problem shape I am building. What earns it a full note is that it is the only paper in the vault that implements <font color="#ffff00">abstention</font>, and abstention is the missing half of my main gap. My orchestration argument has always had two parts, that an agent's reliability varies with conditions and that the agents do not know it, and the second part is the one with no published mechanism behind it. AlphaAgents deleted its sentiment agent by hand and FinAgent's auxiliary strategies degraded quietly on ETHUSD, both because nothing in either design could decline to speak. This paper declines to speak, measures what declining costs, and publishes the frontier.

#### Gap it's addressing

- **The accuracy ceiling is the framing, and it is an honest one.** The authors argue that prediction success in the contemporary literature is already significantly high, that exceeding it is increasingly difficult, and that whatever marginal accuracy a more elaborate architecture buys will not meaningfully offset the additional computational burden it brings in. So rather than a new model they propose a new use for the predictions already available, which is a refreshingly modest premise for a stock prediction paper.
- **Black box opacity is treated as an operational problem rather than a compliance one.** The two drawbacks they name are that inference from ML predictions cannot be explained and that accuracy has plateaued, and their answer folds both into one move, since the same local explanation that makes a prediction interpretable also produces the per-class probability used to decide whether to act on it. Explainability here earns its place by doing work, not by satisfying a regulator.
- **LIME had not been wired into a classifier as a trust filter in this literature.** The claim is scoped carefully, that to the best of their knowledge the implementation of the LIME algorithm to a prediction to such a classifier model as we propose here has not been previously proposed in the relevant literature, and the scoping is what makes it defensible, because the general idea of a reject option is old.
- **Reliability is proposed as a decision-maker's dial rather than a model property.** The threshold is set by whoever is trading, so at 0.50 the system is just the base random forest and at 1.00 it speaks only when the forest is unanimous, and everything interesting happens between those.

The premise holding the whole thing up is that a LIME class probability is a meaningful measure of how likely a prediction is to be right. The paper asserts this and never tests it, and since that single assumption carries the contribution I deal with it once, in limitations, rather than relitigating it in every section.

#### Data and setup

Ten years of daily closes per index pulled from TradingView, min-max scaled, then decomposed and split:

| Component | Setting |
| --- | --- |
| Indices | SP500, NI225, XU100, KOSPI, DAX, FTSE100 |
| Period | Jan 2012 to Dec 2021, 2445 to 2530 observations per index |
| Split | 50 / 25 / 25 train, validation, test, sequential |
| Test length | 608 to 629 trading days per index |
| Features | four lagged values of each IMF |
| Stage-1 models | one ANN regressor per IMF, one ANN classifier on IMF0 |
| Stage-2 model | random forest, 250 trees, max depth 37, two input features |
| Target | binary direction of the scaled original close at $t$ against $t-1$ |
| Metrics | accuracy, precision, recall, F1, ROC-AUC |

Two things in that grid matter more than they look. The lag depth of four is justified in a footnote, fewer than four days degrades prediction performance while more than five shows no significant gain, which is a real if informal search and worth having on record. The second is the split being sequential with the validation block sitting between train and test, because LIME is fitted and the reliability level chosen on that middle block, so the threshold is at least not selected on the data it is evaluated on.

> [!WARNING]
> **The decomposition runs on the entire dataset before the split.** The authors state this plainly in the discussion, noting that in the literature including this paper, the entire dataset, training, validation and test, has to be decomposed beforehand, and then recommend a sliding-window procedure for practitioners without rerunning anything under it. EMD is a global operation, every IMF at time $t$ is a function of the whole series including its future, so the leak is structural rather than incidental. Every accuracy number below carries it.

#### Model architecture and training

Stage 1 is a division of labour between two ANNs, both two hidden layers of 100 ReLU nodes, both trained 300 epochs at mini-batch 30. ANNR takes four lagged values of an IMF and predicts its next value, one output node, tanh activation, MSE loss, Adam. ANNC takes four lagged values of IMF0 specifically and predicts its direction, sigmoid output, binary cross-entropy. The split exists because Table 1 shows the classifier is substantially better on IMF0, the highest-frequency and hardest component, while the regressor is better on everything above it, so each component is handled by whichever model wins on it.

![[Pasted image 20260927143001.png]]

The trick that makes stage 2 work is what gets passed forward. Summing the IMF regressions gives a reconstructed level $\hat{y}_t$, which on its own is a point forecast and not directly useful to a classifier, so they difference it:

$$d_t(\hat{y}) = \hat{y}_t - \hat{y}_{t-1}$$

which carries both the predicted direction in its sign and, as the paper puts it, the severity of the increase or decrease in its magnitude. Alongside it goes $\hat{\sigma}_t(x)$, the raw sigmoid output of ANNC on IMF0, deliberately <font color="#ffc000">not thresholded into a class label</font>, on the reasoning that outputs closer to one or zero predict upward and downward movements more successfully, so the soft value carries information the hard label would discard. The random forest in stage 2 therefore sees exactly two numbers, a signed magnitude and a soft confidence, and nothing else.

LIME then explains each forest prediction by fitting a locally faithful interpretable surrogate around it:

$$\text{explanation}(x) = \underset{g \in G}{\arg\min}\ \mathcal{L}\left(f, g, \Pi_x(z)\right) + \Omega(g)$$

where:
- $f$ is the forest's probability that $x$ belongs to a class
- $g \in G$ is a candidate interpretable model and $\Omega(g)$ penalises its complexity
- $\Pi_x(z)$ weights perturbed samples $z$ by proximity to $x$, defining the locality

The surrogate's class probabilities, which the paper calls explanation prediction probabilities, become the reliability score. The paper states the decision rule in words rather than symbols, so this formalisation is mine, and it is the piece I would reimplement:

$$\text{cover}(\tau) = \frac{1}{T}\sum_{t=1}^{T} \mathbb{1}\left[\max_c p_c(x_t) \ge \tau\right], \qquad \text{acc}(\tau) = \frac{\sum_t \mathbb{1}\left[\hat{y}_t = y_t\right]\mathbb{1}\left[\max_c p_c(x_t) \ge \tau\right]}{\sum_t \mathbb{1}\left[\max_c p_c(x_t) \ge \tau\right]}$$

where $\tau$ is the reliability level, $p_c(x_t)$ the LIME probability for class $c$, and days failing the condition contribute to neither the numerator nor the denominator of accuracy, which is what makes the two quantities have to be read together.

#### Findings

- **The base ensemble beats both its ablations on every metric on all six indices, and the XGBoost comparison is not a fair fight.** EMD-ANNRC-RF runs 0.7806 to 0.8010 accuracy, EMD-ANNRC-XGBoost 0.7727 to 0.7878, and the single-stage EMD-ANNR 0.6476 to 0.7352, so the second stage is worth roughly ten accuracy points over stage 1 alone. The authors attribute XGBoost's shortfall to it having more hyperparameters, the default hyper-parameters of the library have been used, which concedes that the RF-over-XGBoost preference is a statement about tuning effort rather than about the algorithms.

  ![[Pasted image 20260927143002.png]]
- **Abstention buys accuracy at a coverage price the paper is unusually willing to quote.** Averaged across the six indices, moving the threshold from 0.50 to 1.00 takes the predicted days from roughly 622 to roughly 100, an 84 percent drop, while accuracy rises 21.87 percent to 0.9639. The intermediate points are the ones worth operating at:

  | Reliability level | Mean coverage | Mean accuracy |
  | --- | --- | --- |
  | $\ge 0.50$ | 100% | 0.7909 |
  | $\ge 0.85$ | 62% | 0.8953 |
  | $\ge 0.95$ | 44% | 0.9369 |
  | $= 1.00$ | 16% | 0.9639 |

  Read down the coverage column rather than the accuracy column. Going from 0.85 to 1.00 buys under seven accuracy points and costs three quarters of the remaining trading days, whereas the first step, 100 percent coverage to 62 percent, buys more than ten. <font color="#ffc000">The useful part of the frontier is over by about 0.85 to 0.90</font>, and the headline 0.9913 sits well past it.
- **The frontier's shape confirms where it breaks, and the authors say so.** Trusted-prediction percentage falls close to linearly against reliability up to roughly 0.90, then collapses, and beyond that point an equivalent increase in the accuracy rate on average is not observed.

  ![[Pasted image 20260927143003.png]]
- **Cross-market robustness fails precisely at the top of the frontier.** At reliability exactly 1, KOSPI gives 0.9913 on 115 days while FTSE100 gives 0.9079 on 76 and DAX 0.9636 on 55, so FTSE100's maximum-reliability result is worse than SP500's at the 0.95 level with four times the coverage. The authors concede it, that although the LIME algorithm fulfills its task as expected, EMD-ANNRC-RF-LIME may need improvement in terms of robustness for higher levels of reliability, which is the correct reading and undercuts any claim that a single threshold transfers between markets.

  ![[Pasted image 20260927143004.png]]
- **The complexity comparisons all come back null, which is useful in itself.** Parallel experiments with VMD and EEMD in place of EMD produced no significant difference observed in terms of hit rates, and preliminary experiments swapping ANN for LSTM likewise showed no significant difference in terms of accuracy, both stated without a test statistic. Taken as a prior rather than a result, on this configuration the decomposition method and the recurrent architecture were not where the performance came from, and the authors keep EMD because it is easier to implement than VMD since VMD requires parameter fine-tuning.

#### Limitations

- **Every number in the paper inherits the decomposition leak, and the size of the effect is unmeasured.** <font color="#ff0000">Decomposing train, validation and test together before splitting means each IMF at time $t$ is constructed with knowledge of the whole series</font>, and the authors identify this themselves and then recommend the fix to other people rather than applying it. The scale of the distortion is guessable from context: [[Deep Learning with Long Short-Term Memory Networks for Financial Market Predictions]] reports 54.3 percent directional accuracy on a leak-free design over 5750 out-of-sample days, and this paper's Table 4 survey of the state of the art runs 0.60 to 0.90 on a literature with the same habit. A base model at 0.7909 on daily index direction is not a result I can take at face value, and the honest position is that the sliding-window version was never run so the leak-free accuracy is unknown.
- **LIME is never shown to add anything over the forest's own probability, and that ablation is the paper's load-bearing missing experiment.** A LIME surrogate is fitted to approximate $f$ locally, and $f$ here is a random forest whose `predict_proba` is already a vote fraction over 250 trees on a two-dimensional input. Thresholding that vote fraction directly costs nothing, needs no perturbation sampling, and would plausibly produce the same frontier. The contribution is explicitly the integration of LIME into a classifier as a trust filter, so the one comparison that would establish the integration matters, LIME probability against base probability at matched coverage, is the one not reported. On this evidence I cannot tell whether the reliability score is a local explanation or the model's own confidence with extra steps.
- **Accuracy rising with the threshold is close to tautological, so the existence of the effect is not the finding.** Any score even weakly ordered with correctness produces an upward-sloping curve here, which is why selective classification and Chow's reject option long predate this. The paper's real content is the numbers on the frontier and the point at which it breaks, and those are genuinely useful, but the framing presents the mechanism itself as the result and the reader has to separate the two.
- **There is no economic evaluation of any kind.** No returns, no Sharpe, no transaction costs, no exposure on abstained days, on a paper whose entire proposal is a trading decision rule. The gap this leaves is specific rather than cosmetic: abstention very plausibly selects quiet days, since a forest fed a signed magnitude will be least confident when that magnitude is near zero and most confident when it is large, but nothing in the paper checks whether retained days carry larger or smaller absolute moves than discarded ones. Without that, 0.9639 accuracy on 16 percent of days is compatible with both a strong strategy and one that trades only when the move is too small to matter.
- **One run, no seeds, no significance tests, and no calibration check anywhere.** Six indices trained once each, no confidence intervals on any figure in Tables 3 or 5, and no reliability diagram testing whether a 0.85 reliability score corresponds to 85 percent realised accuracy, despite the whole design treating the score as a probability the decision maker should read literally. The between-market spread at reliability 1, 0.9079 to 0.9913, is itself larger than several of the differences the paper treats as meaningful.
- **A single index series is the easiest possible setting for this mechanism and the paper stops just short of the hard one.** The conclusion sketches the multi-asset extension, that instead of predicting a single asset's price it is possible to make predictions for more than one price series at the same time and rely on assets which provide the reliability condition, which is the version where abstention becomes a selection problem rather than a timing one, and nothing is run under it.

#### Why this matters for my project

- **Take the abstention protocol, which is the published mechanism my orchestration argument has been missing.** The gap has always rested on agents that cannot decline, with the sentiment agent asked about a counter with no news as the canonical case, and this paper supplies the shape of the fix along with the discipline for reporting it: never a bare accuracy, always accuracy paired with coverage at a swept threshold. Adopting the sweep costs almost nothing and it converts the empty-channel problem from an argument into something I can put a number on, since the coverage curve for the sentiment agent on CSE counters is directly the measurement of how often that channel is actually live.
- **Pre-register the ablation the paper skipped, because my version has to survive it.** Threshold the classifier's own probability against the LIME score at matched coverage and report both curves whatever they show. If they coincide, the honest statement is that the reliability score is the base model's confidence and LIME is presentation, which still leaves the abstention contribution intact and simply relocates it. This is the same discipline as the pre-registered weight-entropy diagnostic on the orchestrator, a named test whose negative outcome I have already committed to publishing.
- **Realised conditional accuracy is the common scale for heterogeneous agent confidence, and this paper is the argument for it.** The open question in my matrix is how an LLM analyst, an econometric estimator and an RL policy produce comparable confidence numbers, and the answer this suggests is not to compare their raw scores at all but to map each agent's score through its own empirical $\text{acc}(\tau)$ curve estimated on a rolling validation window. That transform lands every agent in the same unit, probability of being right at the score it just emitted, which is comparable across architectures in a way that a softmax output and a posterior variance are not. It also inherits the calibration problem named above rather than solving it, so the curve has to be re-estimated as conditions move rather than fitted once.
- **On the CSE, an abstention threshold is partly a liquidity screen and I need to say which.** Their multi-asset sketch becomes the actual use case here, since with a couple of hundred tradable counters the rule trades whichever clear the bar on a given day, but the counters clearing a confidence bar are very likely the ones printing densely, and Dissanayake and Nanayakkara's illiquidity result in [[Role of Market Liquidity in Sentiment-Based Return Predictions, Evidence from Sri Lanka]] says that set behaves differently from the thin end of the board. So the check is to regress trusted-day frequency per counter on Amihud illiquidity and turnover before claiming the threshold is measuring confidence, which is the same measurement already being computed for the cost model, serving a third purpose.
- **Do not import directional accuracy as a target, and use the frontier's knee rather than its end as the operating point.** The 0.85 to 0.90 band is where coverage is still 44 to 62 percent, and past it the trade is three quarters of the remaining days for under seven accuracy points, which on a market where I need enough trades for the evaluation to have power is not a trade I can make. Combined with the leakage argument, my expectation band for a technical agent on CSE daily direction is somewhere near 0.54 to 0.58 on honest out-of-sample data, and a result above about 0.65 is a prompt to hunt for a leak rather than a success.
- **Evaluate abstention economically or not at all.** Report return per traded day, total return with abstained days held flat, and cost per turn alongside the coverage-accuracy pair, because the failure mode the paper cannot rule out, that confidence concentrates on small-move days, is exactly the one that makes a high-accuracy selective rule lose to buy-and-hold. The abstained days also need an explicit exposure policy, hold the previous position or go flat, since those are different strategies and on the CSE the flat option carries a round-trip cost each time.
- **Decompose in a sliding window or drop decomposition, and read the rest of that literature the same way.** Fitting the transform only on data up to $t$ and recomputing each step is the correct procedure, the authors describe it themselves, and the cost is compute rather than design. This also sets how I read [[FreQuant, A Reinforcement-Learning based Adaptive Portfolio Optimization with Multi-frequency Decomposition]] and any other multi-frequency method in the set, since the question to ask each of them first is where the decomposition boundary sits relative to the test split.
- **Borrow the two-scalar compression into stage 2, and reject the state-blindness that comes with it.** Reducing each upstream component to a signed magnitude and a soft confidence before the combiner sees it keeps the combiner low-dimensional, which matters given how little CSE history I have confirmed, and it generalises cleanly to agents whose internals differ completely. What I cannot borrow is the combiner itself, since a forest over two static features has no channel for liquidity state or volatility persistence and therefore reproduces exactly the fixed-influence design the main gap objects to, the same structural limitation as the near-binary mixture in [[MacroHFT, Memory Augmented Context-aware Reinforcement Learning On High Frequency Trading]]. The compression is the reusable part, the conditioning is mine to add.
