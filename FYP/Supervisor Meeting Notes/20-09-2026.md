# Sentiment was never the source of the strongest novelty

This is important.

Sentiment was actually becoming one of the weaker components because it introduced:

- primary data collection,
- manual annotation,
- annotator disagreement,
- ethics/platform-access issues,
- language adaptation,
- code-mixed NLP,
- dataset validation,
- another independent ML problem.

That could easily consume half the FYP.

Yet none of that directly proves the main proposed contribution.

So dropping sentiment removes a great deal of risk while preserving:

- liquidity novelty,
- volatility-memory component,
- adaptive orchestration,
- heterogeneous agent interaction,
- friction-aware evaluation.

---

# Would dropping sentiment reduce agent diversity?

Slightly, yes.

But that is **not a novelty problem**.

The student still has fundamentally different information sources:

$$Technical \neq Fundamental \neq Risk \neq Liquidity$$

Those agents represent genuinely heterogeneous evidence.

The main research question is not:

> “How many agents can I connect?”

It is:

> **How should heterogeneous agent outputs be coordinated under changing market conditions?**

Three or four well-defined agents are better research than six loosely justified agents.

---

# In fact, fewer agents may improve experimental validity

With too many components, if performance improves, you do not know **why**.

Suppose the original system contains:

- technical model,
- sentiment model,
- RAG,
- fundamental analysis,
- FIGARCH,
- liquidity model,
- RL,
- LLM manager.

If the final return improves by 5%, what caused it?

Very difficult to establish.

With a narrower architecture, the student can run proper ablations:

### Baseline

$$EqualWeight$$

### Baseline 2

$$StaticLearnedWeight$$

### Proposed

$$DynamicStateAwareWeight$$

Then remove:

- liquidity state,
- volatility state,
- persistence,
- confidence.

For example:

$$\begin{gather*}
Proposed - Liquidity \\
Proposed - Persistence \\
Proposed - Confidence
\end{gather*}$$


Now the actual technical contribution becomes measurable.

That is **much stronger research**.
