$$w_{i,t} = f( Liquidity_t, Volatility_t, Persistence_t, Confidence_{i,t} )$$

where the system dynamically changes the influence of specialised agents.

That is much stronger than merely connecting:

> RAG + technical indicators + FIGARCH + sentiment + trader agent.

### Dataset

The student still needs a **sufficiently long, clean, legally usable individual-stock CSE historical dataset** containing enough of:

- Date
- Ticker
- OHLC
- Volume
- Turnover/trading value
- ideally number of trades
- preferably market-cap information

for enough companies and enough years.

That is critical because this dataset supports:

- liquidity state,
- volatility,
- regime identification,
- adaptive orchestration,
- portfolio simulation,
- backtesting,
- walk-forward evaluation.

If only 12–18 months of data is available, the whole experimental design becomes questionable.
