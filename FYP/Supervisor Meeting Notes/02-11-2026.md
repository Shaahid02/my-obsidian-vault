### Issues requiring attention

The declaration states:

`6SENG010W – Software Engineering Final Project`

`6SENG010C – Software Engineering Final Project`

The student must confirm the correct code for this ethics form and amend it if required. The two documents should not carry conflicting identifiers without explanation.

3. Class 1 is not equivalent to completed supervisor acceptance

The form expressly states that supervisor acceptance is recorded separately.

Therefore, the current status is:

Student self-declaration: completed. Supervisor acceptance: not evidenced by the attached form.

It would be incorrect to claim that a separate supervisor acceptance or formal Class 2 review has already occurred.

4. Data permissions require consistency checks

Question 5A.3 is answered No, indicating that the project does not propose data or model use in breach of applicable conditions.

The declaration also states that market data were purchased under a non-commercial student licence.

The underlying permissions should support the proposed extraction, storage, third-party API use and research evaluation. The ethics form alone does not establish those permissions.

5. Public filings and personal information

Although the project does not seek personal data, corporate filings can contain identifiable individuals' names and other information.

The student should check whether these data enter the retrieval pipeline or third-party model APIs. A statement that the project does not intentionally analyse personal data is more precise than assuming that every source document is free of such information.

6. Project end date

The declaration states 1 April 2027. The presentation uses the same date. The student should verify it against the current 6SENG010C final-submission schedule.

The declaration is substantially complete and appears consistent with a Class 1 self-assessment based on the stated activities. The critical remaining checks are the module code, visible title, data-use permissions and separate supervisor acceptance.
